# Passport OCR and ID verification

Looking for an on-premise **passport OCR SDK**, **MRZ reader** (machine-readable zone), or **ID card verification API**? Faceplugin **ID Document Recognition** (Document Reader) classifies the document, runs OCR / MRZ / barcode, and optionally document authenticity — on the phone or on your server (port **8082**). Terms: [Glossary](glossary.md).

* **What it can do:** [ID Document Recognition capabilities](../../products/id-document-recognition-sdk/capabilities.md)
* **Supported documents (PDF):** [catalog](../../products/id-document-recognition-sdk/capabilities.md#document-type-classification--worldwide-coverage) — **16,900** templates, **255** countries
* **Try HTTP:** [Try it](../../getting-started/try-it.md)
* **Install:** [Mobile](../../products/id-document-recognition-sdk/recognition-and-liveness/mobile-sdk/) · [Server](../../products/id-document-recognition-sdk/recognition-and-liveness/server-sdk/)

For face match after the ID scan, see [Face SDK capabilities](../../products/face-recognition-sdk/capabilities.md).
